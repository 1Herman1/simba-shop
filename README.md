# Симба — витрина

Фронтенд интернет-магазина «Симба». React 18 + Vite + Tailwind, разворачивается
на Vercel как статический сайт.

Серверная часть (API, база, админка) живёт отдельно, в репозитории
`1Herman1/project_simba`.

## Запуск локально

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`. По умолчанию запросы уходят на
`http://localhost:3000` — туда, где ожидается локально запущенный сервер.
Другой адрес задаётся в `client/.env`:

```
VITE_API_URL=http://localhost:3000
```

## Как это работает на Vercel

Сайт — одностраничное приложение: сервер отдаёт один `index.html`, а какую
страницу показать, решает уже браузер. Настройки в `vercel.json`:

- **Запросы к `/api/*`** Vercel незаметно перенаправляет на сервер по адресу
  `http://147.45.157.11`. Браузер при этом обращается только к адресу витрины —
  по защищённому `https`. Если бы он ходил на сервер напрямую, браузер заблокировал
  бы такие запросы: незащищённое соединение со страницы, открытой по `https`.
- **Все остальные адреса** отдают `index.html`, иначе переход по прямой ссылке
  вроде `/blog/farmina-vs-monge` возвращал бы ошибку 404.

Адрес сервера меняется в одном месте — в поле `destination` в `vercel.json`.
Когда у сервера появится домен с сертификатом, туда вписывается он.

## Индексация поисковиками

В `client/index.html` стоит `<meta name="robots" content="noindex, nofollow">` —
сайт намеренно закрыт от Яндекса и Google. Снять эту строку нужно в день
запуска на настоящем домене, не раньше: иначе в поиск попадёт технический
адрес вида `*.vercel.app`.
